# NOTICE

The `nerdjb` folder contains only original text files written locally.

## Not vendored

No third-party source code, compiled binaries, game dumps, packages, saves,
firmware, system images, encryption keys, DRM tools, Microsoft/Sony/console DLLs
or SDK binaries are included in this folder.

All functional components are supplied by you in their own locations:

- GE-Proton and its patched `wineserver`
- your `victory.exe` build
- your Proton prefix, saves, cache and FidelityFX directory
- any Windows component DLLs you already placed in your own prefix

Each upstream project keeps its own license. Nothing here grants rights to
game content or console system software.

## No circumvention

`nerdjb` contains no code to jailbreak a console, derive keys, decrypt packages,
bypass DRM, or obtain game files. It assumes your dump and system components are
already lawfully available to you.

## No guarantees

This is not legal advice. Laws and agreements vary by jurisdiction. The design
only avoids bundling or creating protected material; it cannot make a particular
use lawful.
